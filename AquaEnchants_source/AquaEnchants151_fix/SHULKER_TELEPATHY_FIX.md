# Shulker Telepathy Fix

Исправлен баг, при котором шалкер с содержимым становился пустым, если его ломали инструментом с кастомными зачарованиями, например `telepathy` / «Магнит».

## Причина

Эффекты добычи (`TelepathyEffect`, `SmeltEffect`, `LineMineEffect`, `BreakBlockEffect`, `BreakTreeEffect`) отключают ванильный дроп и вручную считают предметы через `Block#getDrops(...)`. Для шалкер-боксов в некоторых версиях Bukkit/Paper такой ручной расчёт может вернуть предмет шалкера без `BlockStateMeta`, из-за чего содержимое не попадало в выпавший предмет.

## Что изменено

- Добавлен `me.aquaenchants.util.BlockDropUtil`.
- Для шалкер-боксов вручную создаётся `ItemStack` того же цвета с `BlockStateMeta` и скопированным инвентарём.
- `TelepathyEffect` теперь кладёт в инвентарь шалкер с сохранённым лутом.
- Массовые эффекты добычи используют тот же безопасный расчёт дропа.
- Переплавка больше не пересоздаёт непереплавляемые предметы без меты: если рецепт переплавки не найден, предмет клонируется с сохранением метаданных.

## Проверка на сервере

1. Положить любой предмет в шалкер.
2. Поставить шалкер в мир.
3. Сломать инструментом с зачарованием «Магнит» / `telepathy`.
4. Проверить, что в инвентарь попал шалкер с тем же содержимым.
