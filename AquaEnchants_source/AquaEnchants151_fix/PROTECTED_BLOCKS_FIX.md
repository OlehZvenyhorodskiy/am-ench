# Protected blocks fix

Изменения:

- `ProtectedBlockUtil` теперь защищает не только `BEDROCK`, но и `END_PORTAL_FRAME`, `SPAWNER`, портальные/служебные блоки, `TRIAL_SPAWNER`, `VAULT`, `REINFORCED_DEEPSLATE`.
- `BlockBreakListener` теперь отменяет `BlockBreakEvent`, если игрок держит предмет с кастомными зачарованиями AquaEnchants и пытается сломать запретный блок. Это важно для `SPAWNER`, который раньше мог сломаться ванильной механикой, потому что обработчик просто выходил без отмены события.
- `VeinMinerListener` дополнительно отменяет событие, если исходный блок защищён.
- Массовые эффекты `BREAK_BLOCK` / `LINEMINE` / `TIMBER` уже используют `ProtectedBlockUtil`; после расширения списка они пропускают новые запретные блоки.
- Экскаватор теперь тоже учитывает расширенную защиту при удалении блоков, движении вниз и очистке воды.
- `items/excavator.yml` и backup получили расширенный `darklist`.

Проверка сборки в этой среде не выполнена: в контейнере отсутствует Maven, а `pom.xml` проекта ссылается на локальную папку зависимостей `C:/1.21.8`.
