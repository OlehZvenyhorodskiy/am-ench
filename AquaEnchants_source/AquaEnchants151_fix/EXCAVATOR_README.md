# Система Экскаватора для AquaEnchats

## Описание

Полноценная система автоматической раскопки чанков с использованием аметистов в качестве топлива.

## Основные возможности

### 1. Установка экскаватора
- Получите предмет: `/aquaenchant giveitem excavator`
- Установите блок в нужном месте
- Система автоматически проверит права доступа ко всему чанку через WorldGuard
- При установке создаётся визуализация (кристалл энда + голограмма)

### 2. Управление экскаватором
- **ПКМ по блоку** - открыть меню "Настройка экскаватора"
- В меню доступно:
  - 6 слотов для аметистов (до 64 штук в каждом)
  - Информация о текущем топливе и количестве слоёв для раскопки
  - 2 кнопки управления:
    - **Левая кирка** - раскопать только ниже экскаватора
    - **Правая кирка** - раскопать весь чанк

### 3. Процесс раскопки

#### Запуск:
1. Поместите аметисты в слоты топлива
2. Нажмите на нужную кирку
3. Обратный отсчёт 5-4-3-2-1 в чате
4. На блоке появляется танцующий пиглин
5. Начинается постепенная раскопка

#### Работа:
- От блока разлетаются частицы наутилуса
- Блоки удаляются слоями от центра к краям чанка
- 1 слой обрабатывается за 5 тиков (0.25 секунды)
- После каждого слоя:
  - Расходуется 1 аметист
  - Экскаватор опускается на блок ниже
  - Обновляется голограмма с количеством топлива

#### Сбор ресурсов:
- Все ценные блоки (руды, древние обломки) не удаляются
- Они собираются в специальный список
- После завершения раскопки все ресурсы появляются в **шалкере на дне чанка**

### 4. Остановка и демонтаж
- Можно сломать блок любым инструментом или рукой
- При разрушении:
  - Процесс раскопки останавливается
  - Удаляются визуальные эффекты (кристалл, голограмма)
  - Данные экскаватора удаляются из базы

### 5. Работа при перезагрузках
- При перезагрузке плагина или сервера:
  - Все данные экскаваторов сохраняются
  - После загрузки процессы раскопки автоматически возобновляются
  - Экскаваторы продолжают работу с того же места

## Технические особенности

### Режимы работы:
1. **BELOW** - удаляет только блоки ниже экскаватора
2. **CHUNK** - удаляет все блоки в чанке (кроме самого экскаватора)

### Белый список блоков (не удаляются, а собираются):
- Все варианты руд (обычные и deepslate)
- Блоки сырых ресурсов
- Древние обломки (Ancient Debris)
- Можно настроить в `items/excavator.yml`

### Защищённые блоки (никогда не удаляются):
- Воздух (AIR)
- Бедрок (BEDROCK)
- Барьер (BARRIER)
- Свет (LIGHT)
- Сам блок экскаватора

### Производительность:
- Обработка по 5 тиков на слой предотвращает лаги
- Постепенное удаление блоков снижает нагрузку на сервер
- Все процессы асинхронны и не блокируют игру

## Файлы проекта

### Новые классы:
1. `ExcavatorData.java` - данные экскаватора (топливо, режим, прогресс)
2. `ExcavatorManager.java` - управление всеми экскаваторами, сохранение/загрузка
3. `ExcavatorGUI.java` - интерфейс меню управления
4. `ExcavatorProcessor.java` - обработка процесса раскопки
5. `ExcavatorListener.java` (обновлён) - обработка событий

### Конфигурация:
- `items/excavator.yml` - настройки предмета и экскаватора
- `excavators.yml` - база данных установленных экскаваторов (создаётся автоматически)

## Команды

```
/aquaenchant giveitem excavator [игрок] [количество]
```

## Требования

- Bukkit/Spigot 1.19+
- WorldGuard (опционально, для проверки регионов)
- Paper рекомендуется для лучшей производительности

## Установка

1. Скомпилируйте плагин с новыми классами
2. Поместите jar в папку `plugins`
3. Перезапустите сервер
4. Настройте `items/excavator.yml` при необходимости

## Баланс

- 1 аметист = 1 слой раскопки
- До 384 аметистов в одной загрузке (6 слотов × 64)
- Это позволяет раскопать до 384 слоёв за одну загрузку
